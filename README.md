## 🎯 How to Play

1. **Guess** a valid 5-letter word.
2. **Submit** with **Enter**.
3. Get instant feedback:
   - 🟩 **Green** — Correct letter in the correct position.
   - 🟨 **Yellow** — Correct letter in the wrong position.
   - ⬜ **Gray** — Letter not in the word.
4. You have **6 attempts** to solve the daily puzzle.
5. A new word appears every day!

**Pro Tip**: Start with words rich in vowels like **"AUDIO"**, **"ARISE"**, or **"CRANE"** for the best information.
